📐 Cloud Subnet Formula & 5 Reserved IPs

In standard IPv4 subnets, $2$ addresses are subtracted (Network + Broadcast). In major clouds (AWS/Azure), 5 addresses are always reserved:

Total Usable Hosts = 2^(32 - Prefix) - 5
CIDR Prefix Total IPs Traditional Usable (-2) Cloud Usable (-5)
/28 16 14 11 Hosts
/24 256 254 251 Hosts
/16 65,536 65,534 65,531 Hosts
• .0: Network address
• .1: VPC router / default gateway
• .2: Cloud DNS resolver
• .3: Future vendor reservation
• .255: Subnet broadcast address

🛡️ Security Groups vs Network ACLs (NACLs)

Exam favorite: the stateful vs stateless boundary in cloud network security.

Security Dimension Security Group (SG) Network ACL (NACL)
Attachment Level Instance / ENI Subnet Boundary
State Awareness STATEFUL (Auto-allows return) STATELESS (Explicit return req.)
Rule Actions ALLOW rules only ALLOW and DENY rules
Rule Evaluation All rules evaluated together Numbered order (lowest first)
Rule of Thumb: Use Security Groups for fine-grained application tier isolation; use NACLs as a coarse subnet perimeter filter (e.g. blocking known malicious IP blocks with explicit DENY).

🚀 The 7 R's Cloud Migration Taxonomy (AWS / Gartner Framework)

1. REHOST
"Lift and Shift"

Move VMs as-is with no architecture changes. Lowest risk, fastest velocity.

2. REPLATFORM
"Lift, Tinker and Shift"

Minor optimizations (e.g. self-hosted MySQL to AWS RDS / Azure SQL) without code rewrites.

3. REFACTOR
"Cloud Native Redesign"

Full rewrite to microservices, containers (K8s), or serverless functions. Maximum agility & scale.

4. REPURCHASE
"Drop and Shop (SaaS)"

Decommission in-house tool and purchase SaaS (e.g. moving on-prem Exchange to Microsoft 365).

5. RELOCATE
"Hypervisor Shift"

Move running VMware instances directly to VMware Cloud on AWS with zero guest changes.

6. RETAIN
"Keep On-Premises"

Leave in existing environment due to strict data sovereignty, low latency, or legacy constraints.

7. RETIRE
"Decommission"

Turn off redundant, dead, or unused legacy workloads identified during discovery.

EXAM TIP

Discovery Phase uncovers 10–20% of servers that can be immediately Retired.
