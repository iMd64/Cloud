SEN421 Midterm Exam: The 42 Master Scenario Questions & Answer Key

This master study guide is dedicated exclusively to the 42 in-class scenario questions, architectural case studies, and diagnostic exercises brought by Dr. Hazm Talab across Modules 1 through 7 (exactly 7 questions per module).

Exam Answering Rule: The professor emphasizes that answers on the midterm should be simple and concise — 1 to 3 words is the primary answer (e.g. "Private Cloud", "Rehost", "Public Subnet", "Non-transitive", "IMDSv2", "Explicit Deny"). Part 1 Module 1 & 2 · Cloud Computing & Virtual Hardware

Module 1 & 2 Scenario Questions (Q1–Q7)

7 Questions

Q1 Scenario: Hospital Patient Records under KVKK

M1 Slide 30 · Case 1

Scenario: A network of hospitals stores sensitive patient medical and health history records under strict personal data protection laws (KVKK / GDPR). Their computing load is highly steady, predictable, and continuous throughout the entire year. Which cloud deployment model should they choose, and why?

Answer Key (1–3 Words): Private Cloud

Short Rationale: Legal data protection compliance mandates exclusive infrastructure isolation, and steady usage makes dedicated hardware cost-effective.

Q2 Scenario: Gaming Startup with Unpredictable Surges

M1 Slide 30 · Case 2

Scenario: A small indie game development startup is launching a new multiplayer game next month. The game might attract only 10 active players, or it could go viral and reach 500,000 active concurrent players. Which cloud deployment model fits their needs?

Answer Key (1–3 Words): Public Cloud

Short Rationale: Wildly fluctuating, unpredictable demand requires rapid elasticity with zero upfront capital hardware purchase.

Q3 Scenario: Bank Core Ledger vs. Web Portal

M1 Slide 30 · Case 3

Scenario: A commercial bank keeps its core customer financial account balances and transaction ledgers strictly in-house in its private data center, but hosts its public-facing marketing website and mobile banking front-end on AWS. Which deployment model is this?

Answer Key (1–3 Words): Hybrid Cloud

Short Rationale: Binds private on-premises infrastructure for regulated records with public cloud for agile external web services.

Q4 Scenario: Shared University Research System

M1 Slide 30 · Case 4

Scenario: Five research universities jointly fund and operate a shared supercomputing and AI research system under identical governance, data security, and academic access rules. Which deployment model describes this environment?

Answer Key (1–3 Words): Community Cloud

Short Rationale: Shared infrastructure operated exclusively for a group of organizations having a common mission and security policies.

Q5 Scenario: Provider for Video and Another for Analytics

M1 Slide 30 · Case 5

Scenario: An enterprise chooses AWS EC2 compute instances for video transcoding pipelines, but sends its data warehouse analytics queries to Google Cloud BigQuery. Which deployment model is this?

Answer Key (1–3 Words): Multi-Cloud

Short Rationale: Intentionally utilizing services from multiple independent public cloud hyperscalers to prevent single-vendor lock-in.

Q6 Scenario: Legacy Windows Software with Specific Hardware Driver

M1 Slide 37 · Self-Check

Scenario: An engineering team must run an older Windows application that requires one specific physical device driver and an exact historical Windows Server build. Which cloud service model fits this requirement?

Answer Key (1–3 Words): IaaS

Short Rationale: Only Infrastructure as a Service grants complete operating system and driver control; PaaS and SaaS permit neither custom drivers nor OS builds.

Q7 Scenario: Student Registration System 40x Traffic Surge

M1 Slide 18 & 19 · Discussion

Scenario: A university student registration portal experiences 40 times normal user traffic during registration week, while sitting mostly idle for the remaining 51 weeks. Rather than buying 40 physical servers that sit idle, which cloud characteristic / operational model solves this?

Answer Key (1–3 Words): Rapid Elasticity

Short Rationale: Pay only for compute resources actively running during surge week; automatically autoscale instances out when traffic spikes and scale in when done.

Part 2 Module 3 · Migration to the Cloud

Module 3 Scenario Questions (Q8–Q14)

7 Questions

Q8 Scenario: Timesheet App with Data Center Closing in 3 Months

M3 Slide 15 · Case 1

Scenario: An internal employee timesheet application runs on its own dedicated server and performs well. The physical on-premises data center lease expires in three months and will be shut down. Which of the 7 R's migration strategies fits?

Answer Key (1–3 Words): Rehost

Short Rationale: "Lift and Shift" moves the virtual machine as-is with zero code changes, meeting the urgent 3-month deadline.

Q9 Scenario: Self-Hosted Email Burning Staff Time

M3 Slide 15 · Case 2

Scenario: A company runs its own on-premises email server, and two full-time systems administrators spend half their weekly working hours patching, troubleshooting, and maintaining it. Which 7 R's strategy should management adopt?

Answer Key (1–3 Words): Repurchase

Short Rationale: "Drop and Shop" abandons the self-managed email server and replaces it with a turnkey SaaS solution (Microsoft 365 / Google Workspace).

Q10 Scenario: Reporting Tool with Last Login 18 Months Ago

M3 Slide 15 · Case 3

Scenario: An enterprise discovery tool scans application usage and reveals an old departmental reporting software instance whose last successful user login was eighteen months ago. Which 7 R's strategy fits?

Answer Key (1–3 Words): Retire

Short Rationale: Safely decommission and turn off dead, unused software to immediately eliminate hosting, power, and licensing costs.

Q11 Scenario: Holiday Peak E-Commerce Elasticity

M3 Slide 15 · Case 4

Scenario: An e-commerce shop slows down and crashes during every holiday shopping season. The business requires the platform to scale out automatically during traffic spikes and scale back in when traffic drops. Which strategy fits?

Answer Key (1–3 Words): Refactor

Short Rationale: Re-architecting into cloud-native microservices, serverless components, and autoscaling tiers unlocks true horizontal elasticity.

Q12 Scenario: Lab Machine Connected to Physical Hardware

M3 Slide 15 · Case 5

Scenario: A specialized medical laboratory workstation is connected via a direct physical cable to an on-site analog spectrometry device. Which 7 R's strategy applies?

Answer Key (1–3 Words): Retain

Short Rationale: Specialized physical hardware attachments and sensor cables cannot be virtualized or migrated across wide-area networks.

Q13 Scenario: Disaster Recovery for High-Revenue E-Commerce Store

M3 Slide 40 · Self-Check A

Scenario: An online shopping portal loses tens of thousands of dollars for every hour it is down, and cannot afford to lose any customer purchase orders. What recovery site type, RPO, and RTO are appropriate?

Answer Key (1–3 Words): Hot Site

Short Rationale: Requires an RPO close to zero and an RTO of minutes; real-time active data replication to a hot site is cost-justified.

Q14 Scenario: Disaster Recovery for School Library Catalog

M3 Slide 40 · Self-Check B

Scenario: A school's library book catalog can tolerate being down for an entire day during an outage, and losing the last 24 hours of book search updates is acceptable. What recovery site type, RPO, and RTO fit?

Answer Key (1–3 Words): Cold Site

Short Rationale: Tolerates an RPO of one day and an RTO of one day; daily automated cloud backups restored to a cold site is almost free.

Part 3 Module 4 · Cloud Networking & Subnets

Module 4 Scenario Questions (Q15–Q21)

7 Questions

Q15 Scenario: Placement of Internet-Facing Load Balancer

M4 Slide 27 · Case 1

Scenario: You are designing a VPC for the university course registration website. Should the internet-facing load balancer (ALB) be placed in a Public or Private subnet, and does it require a public IP address?

Answer Key (1–3 Words): Public Subnet

Short Rationale: Yes, it needs a public IP and an Internet Gateway route because external users on the internet must initiate connections to it.

Q16 Scenario: Placement of PostgreSQL Database

M4 Slide 27 · Case 2

Scenario: Where should the PostgreSQL database cluster supporting the registration application be placed, and should it be assigned a public IP address?

Answer Key (1–3 Words): Private Subnet

Short Rationale: No public IP; databases must be strictly isolated from the internet and reached only by internal application servers.

Q17 Scenario: Application Server Downloading OS Updates Nightly

M4 Slide 27 · Case 3

Scenario: An internal application server must download Linux security patches from external internet repositories every night. Should it reside in a public or private subnet?

Answer Key (1–3 Words): Private Subnet

Short Rationale: Place in a private subnet with NO public IP; route outbound internet traffic through a NAT Gateway in a public subnet.

Q18 Scenario: Reporting Machine Reading Files from S3 Cloud Storage

M4 Slide 27 · Case 4

Scenario: A reporting machine reads files from cloud object storage (Amazon S3) every hour and writes reports. Should it have a public address?

Answer Key (1–3 Words): No Public Address

Short Rationale: Place in a private subnet reaching S3 internally through a VPC Gateway Endpoint with zero public internet exposure.

Q19 Scenario: Locating IP Address 10.20.3.77 in Multi-Tier VPC

M4 Slide 16 · Question 2

Scenario: A company receives 10.20.0.0/16 and carves six /24 subnets for Web, App, and DB across Zones A & B. In which subnet does the IP address 10.20.3.77 reside?

Answer Key (1–3 Words): Zone-B Application Subnet

Short Rationale: Allocated as: Web-A (.0), Web-B (.1), App-A (.2), App-B (10.20.3.0/24), DB-A (.4), DB-B (.5).

Q20 Scenario: Usable Hosts in a /24 Subnet on AWS

M4 Slide 16 · Question 3

Scenario: How many usable host IP addresses are available to virtual machines in a standard /24 subnet in an AWS VPC?

Answer Key (1–3 Words): 251 Usable Hosts

Short Rationale: Total IPs are $2^{(32-24)} = 256$; cloud providers reserve exactly 5 addresses (.0, .1, .2, .3, and .255), leaving $256 - 5 = 251$.

Q21 Scenario: Checking if IP 10.0.2.5 Belongs to 10.0.0.0/23

M4 Slide 14 · Worked Example

Scenario: A routing rule applies to CIDR block 10.0.0.0/23. Does the destination address 10.0.2.5 fall inside this block?

Answer Key (1–3 Words): No (Out of Range)

Short Rationale: A /23 contains 512 addresses spanning 10.0.0.0 through 10.0.1.255; 10.0.2.5 belongs to the next block (10.0.2.0/23).

Part 4 Module 5 · Connectivity & Troubleshooting

Module 5 Scenario Questions (Q22–Q28)

7 Questions

Q22 Scenario: Peered Networks A–B and B–C Cannot Reach A–C

M5 Slide 48 · Case 1

Scenario: Network A is peered with Network B, and Network B is peered with Network C. Why is Network A completely unable to reach Network C?

Answer Key (1–3 Words): Non-Transitive Peering

Short Rationale: VPC peering does not support edge routing; you must create a direct A–C peering connection or deploy a Transit Gateway.

Q23 Scenario: Cloud VMs Cannot Reach Office Printer Server

M5 Slide 48 · Case 2

Scenario: Corporate office workstations easily reach cloud virtual machines over the VPN tunnel, but cloud virtual machines cannot initiate a connection to the on-prem office printer server. What is the cause?

Answer Key (1–3 Words): Office Firewall Inbound

Short Rationale: The office edge firewall statefully tracks outbound office connections but blocks new unsolicited inbound connections initiated from the cloud CIDR.

Q24 Scenario: Ping Fails but Website Opens in Browser

M5 Slide 48 · Case 3

Scenario: An administrator runs ping against a cloud web server and receives 100% packet loss, yet the website loads quickly in Chrome on HTTPS. What is the most likely cause?

Answer Key (1–3 Words): ICMP Blocked

Short Rationale: Security Groups drop ICMP echo requests by default, while TCP port 443 (HTTPS) is explicitly allowed. Test the actual service port instead of ping.

Q25 Scenario: Over VPN, Small Pages Work but Large Uploads Hang

M5 Slide 48 · Case 4

Scenario: Over an IPsec VPN tunnel, web login and text pages load normally, but uploading a large PDF report freezes and hangs indefinitely. What is the cause?

Answer Key (1–3 Words): MTU Size Mismatch

Short Rationale: IPsec encryption overhead makes 1500-byte packets exceed MTU; with DF set, packets drop without notice (fix via MSS Clamping ~1388 bytes).

Q26 Scenario: curl to Port 8080 Returns Connection Refused

M5 Slide 48 · Case 5

Scenario: A cloud engineer runs curl http://10.20.4.15:8080 and immediately receives "Connection refused". What does this immediate response signify?

Answer Key (1–3 Words): No Program Listening

Short Rationale: The host kernel responded with a TCP RST; routing works, but the application daemon on port 8080 is crashed or stopped.

Q27 Scenario: Sizing Nightly 2 TB Hospital Backup Transfer

M5 Slide 15 & 16 · Will It Fit?

Scenario: A hospital copies 2 TB of data to the cloud nightly in an 8-hour window between 23:00 and 07:00 at 70% effective throughput. Which link is enough: 100 Mbps, 1 Gbps, or 10 Gbps?

Answer Key (1–3 Words): 1 Gbps Link

Short Rationale: 100 Mbps takes ~63.5 hours (fails); 1 Gbps takes ~6.35 hours (fits inside 8h); minimum required bandwidth is 794 Mbps.

Q28 Scenario: Multi-Failure Database Unreachable After Move

M5 Slide 40 & 41 · Worked Example

Scenario: After overnight updates, office apps fail to reach db.internal.example.com on port 5432. DNS lookup gives NXDOMAIN, and connecting directly by IP times out. What are the two root causes?

Answer Key (1–3 Words): Missing Forwarder & SG

Short Rationale: Office DNS lacks conditional forwarding for the new zone (NXDOMAIN), AND database Security Group omitted the office CIDR rule (Timeout).

Part 5 Module 6 · Securing Cloud Resources

Module 6 Scenario Questions (Q29–Q35)

7 Questions

Q29 Scenario: Cloud Access Key Committed to Public GitHub

M6 Slide 40 · Case 1

Scenario: A student developer accidentally pushes a class coding project to a public GitHub repository. The commit contains a long-lived cloud account access key. What is the fundamental security principle and the immediate first action?

Answer Key (1–3 Words): Revoke Key Immediately

Short Rationale: Deactivate the key in the console at once, then query CloudTrail audit logs to see if unauthorized compute was launched.

Q30 Scenario: Audit Logging Disabled at 02:14 Last Night

M6 Slide 40 · Case 2

Scenario: A morning security review discovers that management audit logging (AWS CloudTrail) was mysteriously disabled at 02:14 last night. What is the principle at stake and the first action?

Answer Key (1–3 Words): Treat as Incident

Short Rationale: Intruders disable logging to hide traces; immediately treat as a security incident, re-enable logging, and identify the rogue principal.

Q31 Scenario: Test Database Holding Real Customer Production Data

M6 Slide 40 · Case 3

Scenario: A software development team clones the entire production database with real customer credit card numbers and addresses into a testing environment. What principle is violated, and what must be done?

Answer Key (1–3 Words): Data Masking

Short Rationale: Production PII must never reside in test environments; delete the copy and replace with synthetic or masked data (Data Minimization).

Q32 Scenario: Critical Zero-Day CVE on Public Web Servers

M6 Slide 40 · Case 4

Scenario: A critical remote code execution CVE is published for the web server software running across an organization's public instances. What is the immediate first action?

Answer Key (1–3 Words): Patch Public Machines

Short Rationale: Practice patching by business risk: patch internet-exposed machines first within days, apply a WAF rule, then patch internal tiers.

Q33 Scenario: Storing Turkish Customer Data Abroad

M6 Slide 40 · Case 5

Scenario: A company operating in Istanbul plans to store Turkish customer personal data in an AWS Frankfurt or Azure Ireland cloud region. What compliance requirement applies?

Answer Key (1–3 Words): KVKK Transfer Abroad

Short Rationale: Enforces data sovereignty: map all cross-border data flows, execute standard contractual clauses, and notify the KVKK board.

Q34 Scenario: Capital One Breach via Cloud Metadata Service

M6 Slide 39 · Case Study

Scenario: In the 2019 Capital One breach, an attacker exploited an SSRF vulnerability in a WAF to query the internal metadata IP (169.254.169.254) and steal role credentials. What cloud defense stops this attack?

Answer Key (1–3 Words): IMDSv2

Short Rationale: IMDSv2 enforces an HTTP PUT session token that SSRF proxies cannot forge, neutralizing metadata credential exfiltration.

Q35 Scenario: Calculating Annualized Loss Expectancy (ALE)

M6 Slide 14 · Worked Example

Scenario: A customer database is valued at $4,000,000. An outage causes half the value to be lost (SLE = $2,000,000). Historical rate of occurrence is estimated at once every 10 years (ARO = 0.1). What is the Annualized Loss Expectancy?

Answer Key (1–3 Words): $200,000 / Year

Short Rationale: $ ext{ALE} = ext{SLE} imes ext{ARO} = $2,000,000 imes 0.1 = $200,000$. A security control costing $50k/yr is easily cost-justified.

Part 6 Module 7 · Identity and Access Management (IAM)

Module 7 Scenario Questions (Q36–Q42)

7 Questions

Q36 Scenario: Five Developers Sharing One Administrator Login

M7 Slide 40 · Case 1

Scenario: Five software developers share a single cloud root/administrator login "to save time and share credentials". What fundamental IAM principle is violated, and what is the fix?

Answer Key (1–3 Words): Individual IAM Identities

Short Rationale: Shared accounts eliminate individual accountability and auditability; assign each developer a unique identity in a role-based group with mandatory MFA.

Q37 Scenario: Staff Member Signs In Six Months After Leaving

M7 Slide 40 · Case 2

Scenario: An IT audit discovers that a former employee who left the company six months ago is still actively signing in to the corporate cloud management console. What lifecycle process failed, and what is the permanent architectural solution?

Answer Key (1–3 Words): Automated Offboarding (SCIM)

Short Rationale: A missing leaver workflow left orphaned credentials; integrate cloud IAM with central HR IdP using SCIM protocol to automate immediate deprovisioning.

Q38 Scenario: Backup Script with Hardcoded Access Key in Plain File

M7 Slide 40 · Case 3

Scenario: A nightly database backup script running on a cloud virtual machine authenticates to object storage using an AWS access key and secret key saved in a plain text configuration file. What is the security flaw and the modern cloud fix?

Answer Key (1–3 Words): IAM Instance Role

Short Rationale: Long-lived static keys leak easily; attach an IAM instance role / managed identity to the VM so the cloud issues short-lived, auto-rotating temporary credentials.

Q39 Scenario: Cloud Root Account Used Daily Without MFA

M7 Slide 40 · Case 4

Scenario: Cloud administrators routinely log in with the root account every day to perform routine maintenance tasks without any multi-factor authentication (MFA). What is the mandatory architectural fix?

Answer Key (1–3 Words): Lock Root Away

Short Rationale: The root account possesses unrestricted blast radius; secure it with hardware MFA, lock credentials away, and conduct daily admin tasks via delegated IAM roles.

Q40 Scenario: QA Tester Retains DB Delete Rights Across Three Team Moves

M7 Slide 40 · Case 5

Scenario: Over three years, an employee transitioned through three departments (Support → QA Tester → Frontend Dev) and still retains permissions to drop production databases granted during their very first assignment. What is this security defect and how is it eliminated?

Answer Key (1–3 Words): Privilege Creep (Reviews)

Short Rationale: Privilege creep occurs when employees accumulate privileges over time; enforce formal Joiners-Movers-Leavers (JML) workflows and periodic access recertification reviews.

Q41 Scenario: IAM Policy Evaluation Conflict for Mehmet

M7 Slide 24–25 · Policy Evaluation

Scenario: User Mehmet is attached to Policy 1 (Allow Read in shop-reports), Policy 2 (Allow Read & Delete in all buckets), and an organizational SCP Policy 3 (Deny Delete in audit-logs). Mehmet issues an API call to delete an object inside the audit-logs bucket. Is the action permitted or denied, and why?

Answer Key (1–3 Words): No (Explicit Deny)

Short Rationale: In cloud IAM evaluation logic, an explicit deny always beats any allow statement regardless of where it is declared.

Q42 Scenario: Password Combined with Mother's Maiden Name

M7 Slide 12 · Exam Trap

Scenario: A cloud application login screen prompts users for their password, followed by a security challenge question ("What was your mother's maiden name?"). Does this configuration satisfy Multi-Factor Authentication (MFA)?

Answer Key (1–3 Words): No, Single-Factor

Short Rationale: Both questions represent the same factor category ("something you know"); true MFA strictly requires two or more distinct factor types.
